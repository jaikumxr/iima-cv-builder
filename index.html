Saving as PDF

The browser print dialog is about to open. It produces a true vector PDF — sharp, selectable text at the exact A4 size, which is what recruiters' ATS tools want.

  1. Set Destination to Save as PDF — not Microsoft Print to PDF, which sits next to it in the list and rasterises the page, giving you a picture of a CV that nobody can select or search
  2. Set Margins to None (the CV carries its own 0.5 inch margins)
  3. Turn Headers and footers off
  4. Leave Background graphics on, or the heading bars print white
