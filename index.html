Saving as PDF

In the print dialog that opens:

  1. Destination: Save as PDF — not Microsoft Print to PDF, which rasterises the page
  2. Margins: None — the CV carries its own
  3. Headers and footers: off
  4. Background graphics: on, or the heading bars print white

This will run to two pages

Garamond stays at 10 pt — the size the format specifies — so the only way to reach one page is to cut text.

Bring in a CV you already have

  1. Press Copy the prompt.
  2. Open ChatGPT, Claude or Gemini. Paste it, and attach your CV.
  3. Save its reply as a file ending in .json.
  4. Come back here and press Choose file.
